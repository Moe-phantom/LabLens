# LabLens

LabLens is an AI-powered microbiology assistant for petri dish analysis.

The system combines computer vision and multimodal AI to:
- detect and count bacterial colonies
- analyze colony density and contamination
- generate AI-assisted lab notes

## Initial MVP
- Upload petri dish image
- Colony counting with OpenCV
- AI-generated experiment summary

## Planned Features
- Cellpose segmentation
- Historical experiment memory
- Contamination detection
- Automated lab notebook generation
